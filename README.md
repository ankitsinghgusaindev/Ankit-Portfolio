##Installation

Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

Move to project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
