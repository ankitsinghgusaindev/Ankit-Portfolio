## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/ankitsinghgusaindev/Ankit-Portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Ankit-Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```
